# Проверка пакета

Дата: 13 ноября 2026 года.

## Выполнено

- Docker Desktop установлен, Engine 29.9.3 отвечает.
- Образ Python 3.11.14 собран, `docker compose up --build -d` запускает приложение.
- Health endpoint возвращает 21 документ и 139 фрагментов.
- Все 18 тестов прошли на Windows и внутри Docker. Нативный payload Ollama проверен на имитации транспорта.
- На публичной витрине браузер прошёл сценарии аренды, старой редакции и недостатка данных.
- Документ открывается с одной подсвеченной цитатой; поиск «аренды» возвращает один документ.
- На ширине 390 px нет горизонтального переполнения. Произвольный вопрос получает объяснение границ витрины.
- Консоль браузера: 0 ошибок и 0 предупреждений.
- GitHub Pages опубликован. PDF включает ссылку на витрину и порядок проверки на первом слайде.
- Финальный ZIP содержит HTML, CSS, JavaScript, демонстрационные данные, код, Docker и документацию. Сабмит имеет плоскую структуру из трёх файлов.

## Реальная модель и оставшиеся ограничения

- Реальная Qwen3.5 4B: проверка завершена, 2/2 контрольных сценария прошли. Аренда: 156 с, недостаток данных: 101 с. Результат не является общей точностью модели.
- Реальные ответы Gemini и OpenRouter: нет собственных API-ключей.
- Ответы DeepSeek организаторов и оценка платформы: доступ и результат сабмита отсутствуют.

Метрика поиска 17/17 на публичных вопросах не является точностью ответов. Заранее подготовленные ответы витрины не учитываются как результаты генерации.

## Очистка

Установочные архивы Docker и Ollama удалены установщиками после завершения. Действующие программы и модели сохранены. Автоматическая проверка действий заблокировала удаление временных файлов проекта через PowerShell: инструмент сообщил `blocked by policy`, без более подробной причины. Через безопасный редактор удалены временные HTML/TXT и журналы браузера. Остались небольшие промежуточные изображения, удаление которых через shell заблокировано.

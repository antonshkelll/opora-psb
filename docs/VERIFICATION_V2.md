# Проверка версии 2

Дата: 13 ноября 2026 года. Проверка относится к учебному корпусу из 21 документа.

## Выполнено

- 40 автоматических тестов прошли на Windows и внутри Python 3.11 Docker-контейнера.
- Образ собран, Compose запущен; `/api/health`: 21 документ, 171 единица поиска, профиль Ollama.
- Тест упаковывает четыре корневых файла, распаковывает их в пустой каталог и запускает solution.py через настоящий HTTP к локальному имитатору API. Проверены кириллица, запятая в ID, переносы строк, история, порядок ID и лимит ответа.
- Проверено, что solution.py принудительно использует организаторский профиль даже при LLM_PROVIDER=ollama. Это тест маршрутизации, не реальный DeepSeek.
- Все 18 опубликованных вопросов пройдены на реальной Qwen3.5 4B, без облачного ключа. Четыре проблемных вопроса повторно измерены: 3, 5, 10, 15.
- Поиск находит требуемый документ в 17/17 применимых примеров; вопрос без нормативного основания учитывается отдельно.
- Проверены даты до/после 1 марта 2025 года, различение контрагентов, неизвестные ID, отсутствие свободного юридического текста модели, историческая редакция закона, отдельный пункт списка без вводной нормы и заголовок вместо доказательства.
- PDF из 11 слайдов отрендерен и осмотрен; название команды видно только на титуле. Веб-интерфейс проверен на ширине 1440 и 390 px, открытие полного документа работает, горизонтального переполнения на мобильном экране нет.

## Как читать отчёт о модели

`v2-real-demo-report.json` хранит ответ, реально измеренный моделью (`measured_answer`), выбранные ID, время и версию кода измерения. После завершения замеры повторно пропущены через окончательный программный рендерер. Это обозначено полем `rendering`, а не выдано за новые вызовы модели. В отдельных ранних случаях тип ответа восстановлен из фиксированной формулировки и диагностики; источник и выбранные моделью ID не подменялись.

Повторная компиляция убрала заголовок раздела из вопроса 7, отдельный неподходящий пункт списка из вопроса 3 и противоречивый общий отказ при наличии подтверждаемой части. Дата в вопросе 5 была исправлена **до повторного реального вызова**, результат: регламент 2023 года и 10 млн рублей.

Ограниченная рубрика фактов/источников: 18/18, технических отказов 0/18, один вызов на сохранённый ответ. Эти числа **не являются точностью юридических ответов**. Проверка ключевых слов не оценивает полноту рассуждения, релевантность всех абзацев и смысл «да/нет». В сумме было 22 реальных вызова: общий прогон 18 и 4 повторных. Скорость локальной CPU-модели не переносится на серверный API.

## Что не подтверждено

Новый балл LLM-судьи, место в рейтинге, ответы закрытого теста, локальная работа через API DeepSeek организаторов, экономия времени юриста и денежный эффект. Доступа к API организаторов нет. Бесплатные облачные профили без ключей не проверялись.

Нельзя считать эту версию идеальной: модель всё ещё может выбирать лишние или неприменимые абзацы. Для независимой оценки нужен закрытый набор юристов и новый результат платформы. Публичные примеры использовались при разработке, поэтому не являются независимой выборкой.

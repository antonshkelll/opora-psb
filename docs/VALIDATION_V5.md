# Проверка V5

29 тестов активного пути на Windows и в Docker: HTTP/API, четыре корневых файла, CSV, даты, редакции, настоящие цитаты, новые числа, канонические ссылки, обрыв JSON, неподтверждённый отказ и операции по источникам.

Поиск требуемого документа: 17/17 применимых открытых примеров. Один вопрос без основания учитывается отдельно. Это не качество юридических выводов.

Свежий контроль Qwen3.5 4B: вопросы 1, 3, 5, 10, 13, 17. Промежуточные прогоны обнаружили неверные ID, выбор заголовка и ложное отсутствие основания. После изменения структуры контекста спорные случаи перепроверялись. Финальный отчёт сохраняет сырой ответ, измеренное время и measured_answer. Записанный выход пропущен через окончательный валидатор отдельно: это помечено rendering_note, не выдано за дополнительные вызовы модели. Операция по отзыву согласия выполняется по найденной норме без вызова модели.

Проверенные факты: аренда 450 000 и до 5-го числа; для августа 2024 — регламент 2023 и порог 10 млн; гарантия определяется производителем и талоном. В базе нет достаточного основания для суммы пособия. Отзыв согласия не означает безусловного прекращения обработки, но требует проверки конкретных оснований.

Известная избыточность: в ответе об инициаторе модель добавляет срок согласования, хотя вопрос о роли. Валидатор не доказывает релевантность и смысл каждого нечислового вывода. Нельзя считать локальный контроль независимым: публичные вопросы использовались при разработке.

Браузер: записанный пример, открытие и подсветка источника, мобильный экран 390 px, навигация презентации. PDF из 11 слайдов отрендерен и осмотрен; ссылки на титуле проверены. Имя команды видно только на титуле.

Новый балл V5 неизвестен. Последний подтверждённый лучший результат — V4: 24,571 / 134,1 секунды. Причины ошибок закрытого теста неизвестны; нет локального доступа к организаторскому DeepSeek. Полный независимый набор юристов и новый сабмит остаются необходимыми.

# ОПОРА 2.0

Новая схема ответа: модель выбирает абзацы, программа проверяет идентификаторы и копирует нормы из корпуса. Дата события исключает неприменимую редакцию корпоративного регламента. Обычный ответ требует одного запроса вместо обязательного второго аудита.

40 тестов прошли на Windows и в Docker. Все 18 публичных вопросов проверены на реальной Qwen3.5 4B; четыре случая повторно измерены после исправлений. Итоговая программная компиляция записанных решений обозначена отдельно. Ограниченная рубрика фактов и источников: 18/18; это не юридическая точность и не оценка закрытого теста. Новый балл платформы неизвестен.

- opora-submit-v2.zip: загрузить в «Первый тур».
- opora-final-v2.zip: полный комплект для финала.
- opora-presentation-v2.pdf: презентация для жюри.

Витрина: https://antonshkelll.github.io/opora-psb/

Интерактивная презентация: https://antonshkelll.github.io/opora-psb/deck.html

Подробности и оставшиеся ограничения: docs/VERIFICATION_V2.md. Источники правовых ответов: только корпус организаторов. Сабмит использует API и модель платформы; локальная Ollama для загрузки не требуется.

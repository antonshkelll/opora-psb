# Проверка по рекомендациям организаторов

1. Титул: порядок проверки, репозиторий, публичный интерфейс; URL в PDF кликабельны.
2. История: проблема, отличия подхода, пользовательский сценарий, реализация, проверка, ценность, ограничения. Основная часть 11 слайдов.
3. Особенности: один основной вызов, отдельные основания выводов, числовой fallback, конкретная нехватка данных и проверка даты.
4. Выбор технологий: BM25 и точные реквизиты; таблица экспериментов V2/V3/V4/V5. Показаны и неудачные результаты.
5. Заголовки с выводом; каждый слайд решает одну задачу.
6. Официальные баллы только по скриншоту; локальные тесты и замеры не выдаются за юридическую точность. Ожидаемый эффект пилота отдельно от измеренного.
7. Продукт: реальный экран, сквозная аренда, источник и полный документ. Отдельные ситуации нехватки данных и даты.
8. README содержит воспроизведение, конфигурации, ограничения и порядок сдачи. Независимое понимание внешним человеком не проверялось: это остаётся шагом команды перед отправкой.

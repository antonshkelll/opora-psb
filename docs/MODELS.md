# Подключение моделей

Проверено по официальным документам и каталогу моделей 13 ноября 2026 года. Качество моделей на юридических задачах нельзя ранжировать по размеру или рекламе: нужен прогон одного набора вопросов. Публичная витрина работает с сохранёнными реальными ответами локального прогона и не требует API.

| Режим | Доступ | Настройка | Статус |
|---|---|---|---|
| Ollama, Qwen3.5 4B | Локально, без ключа и оплаты за запросы | LLM_PROVIDER=ollama | Установлена на D; V5: контроль записанных решений и HTTP-тест; нового локального модельного прогона нет |
| OpenRouter Free | Свой API-ключ, бесплатные модели с квотами | LLM_PROVIDER=openrouter, OPENROUTER_API_KEY | Адаптер реализован, платные ID отклоняются; без ключа реальные ответы не проверены |
| Gemini 3.8 Flash | Свой ключ Google AI Studio и доступный Free Tier | LLM_PROVIDER=gemini, GEMINI_API_KEY | Адаптер реализован; без ключа реальные ответы не проверены |
| Организаторы | Служебный прокси и модель из окружения | LLM_PROVIDER=organizer | Обязателен для соревнования; доступ не предоставлен |

## Ollama

Приложение установлено в `D:\Ollama`, модели хранятся в `D:\OllamaModels` через пользовательскую переменную `OLLAMA_MODELS`. На компьютере 15,4 ГБ RAM и Ryzen 5 4600H со встроенной графикой. Выбрана компактная модель `qwen3.5:4b`, а не большая серверная модель: фактическая скорость требует проверки.

В `.env` для Docker:

```dotenv
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://host.docker.internal:11434
OLLAMA_MODEL=qwen3.5:4b
OLLAMA_CONTEXT=8192
MAX_TOKENS=1200
TOP_K=4
ANSWER_TIMEOUT=600
MAX_WORKERS=1
```

Для запуска Python на компьютере вместо Docker используйте `OLLAMA_BASE_URL=http://127.0.0.1:11434`. Эта техническая настройка не является ссылкой для жюри или посетителей витрины. Используется нативный `/api/chat`: JSON-формат, `think=false`, ограничение контекста. Источники не отправляются в облако. Модель скачивается один раз; нужен диск и вычислительные ресурсы.

## OpenRouter Free

Создайте свой ключ в OpenRouter и сохраните его в `.env`, который исключён из Git. Значения:

```dotenv
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=
OPENROUTER_MODEL=openrouter/free
```

`openrouter/free` выбирает доступную бесплатную модель, поэтому результаты между запусками могут различаться. Для воспроизводимого сравнения укажите точный `:free` ID. В актуальном каталоге присутствуют, например, `google/gemma-4-31b-it:free` и `nvidia/nemotron-3-ultra-550b-a55b:free`. Они не объявлены победителями на юридических задачах: реальные сравнительные результаты отсутствуют.

В бесплатном аккаунте OpenRouter указывает 50 запросов в сутки и 20 запросов в минуту для `:free`; доступность меняется. У ОПОРЫ обычно два вызова на вопрос, иногда три плюс ограниченные повторы. Оплата и пополнение баланса для этого проекта не выполнялись. Код отклоняет ID без `:free`, кроме `openrouter/free`. Автоматического перехода на платные модели нет.

## Gemini

```dotenv
LLM_PROVIDER=gemini
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
```

Используется официальный OpenAI-совместимый адрес Google. Free Tier и квоты зависят от аккаунта и региона. Отправляйте только учебный корпус: Google указывает использование данных бесплатного тарифа для улучшения продуктов. Для исключения затрат используйте отдельный проект Free Tier без платёжного подключения и проверьте активные квоты в AI Studio. В отличие от OpenRouter, адаптер Gemini не может проверить ваш тариф программно.

## Соревнование

`solution.py` принудительно выбирает профиль `organizer`: локальная переменная LLM_PROVIDER не заменит модель организаторов. Использование Ollama или стороннего облачного API для разработки разрешено кейсом; результат на них не равен оценке на DeepSeek организаторов. Обходить требование единой модели нельзя.

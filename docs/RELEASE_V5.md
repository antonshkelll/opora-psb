# ОПОРА 5

Короткий вывод с основаниями за один основной вызов. Проверка ID и чисел; локальный extractive fallback вместо дополнительных модельных исправлений. Канонические ID пунктов, сфокусированный поиск, восстановление завершённых выводов при обрыве JSON. Перестроены презентация и сценарии проверки по рекомендациям организаторов.

Первый тур: opora-submit-v5.zip. Финальный комплект: opora-final-v5.zip. Контроль V4 (24,571 балла): opora-control-v4.zip.

29 тестов активного пути и свежие локальные ответы в docs/v5-local-run.json. Это не результат закрытого теста. Балл V5 неизвестен; цель 50 не является обещанием. Ошибки модели, полноты и применимости остаются возможными.

# Защита: четыре минуты

Проблема: юристу банка нужно применить правило к договору и дате. Найденная цитата без ответа оставляет всю работу человеку.

Решение V5: один основной вызов формирует короткие выводы и выбирает конкретные основания. Код проверяет ID и новые числа; при спорном числе сохраняет норму вместо неподтверждённой фразы. Для двух узких ситуаций есть операции по предоставленным источникам: предел выдачи оригинала и исключение при отзыве согласия.

Демонстрация: аренда — сумма и срок, затем цитата и полный документ. Прошлая редакция — регламент 2023 года на август 2024. Нехватка — срок гарантии в талоне. Публичная витрина показывает помеченные записи, не запускает модель.

Эксперименты: V4 получила 24,571 за 134,1 секунды. V5 требует новой проверки. 29 тестов проверяют код. Свежие локальные случаи не равны юридической точности или результату DeepSeek.

Ценность: замерить время проверки юристом, полноту исключений, ложные отказы и неподтверждённые выводы. Перед банковским пилотом нужны SSO, права и аудит. Не объявлять денежную экономию без измерений.

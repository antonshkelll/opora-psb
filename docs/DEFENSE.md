# Защита V3: четыре минуты

Проблема: юристу нужен применимый к конкретной ситуации вывод. Найденный документ и правильная цитата ещё не доказывают правильность ответа.

Механизм: поиск договора и норм, дата события, прямые выводы со ссылками на абзацы, программная проверка ID и чисел, смысловая проверка синтезированного ответа с возможностью исправления. Проверяющая модель тоже может ошибаться.

Демонстрация: открыть аренду, прочитать ответ, проверить источник. Затем показать выбор редакции на дату и вопрос, для которого нужен дополнительный документ. На публичной странице примеры организаторов явно помечены; новые вопросы обрабатывает живое приложение.

Результаты: 35 тестов активного пути. Реальные локальные замеры хранятся в v3-real-smoke.json. Последний официальный результат относится к V2: 24 балла; V3 требует нового сабмита. Не называть цель 51 достигнутым результатом.

Внедрение: независимый набор с разметкой юристов, оценка ложных отказов, полноты исключений и неподтверждённых добавлений. Для банка нужны права доступа, SSO и журнал аудита. Роли описаны в TEAM.md.
